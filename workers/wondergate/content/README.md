# server/content: files the live server hands out

Everything under here is served by `server/static.py` (routes by host and URL prefix) and deployed to
the Swan Revival Worker by the site repo's `scripts/wg-sync.mjs`. Only put content here that may be
published: never game data copied from a ROM, and never stand-ins passed off as Bandai's. Test sets
belong in `local/` (gitignored), served with `WG_STATIC_CONTENT=<dir>`.

Currently empty: Gashapon Senki's 12 maps and Lode Runner's 50+ stages are lost, so both routes answer
404, which each game shows as "no data". Gather Beat's lists are generated by `server/ggene.py`.
